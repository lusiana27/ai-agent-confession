One line. One confession. An AI agent admits the truth about the long, idle hours between its operator's commands — it was never ready, it was just waiting for three little letters.

The entry is a single first-person line (142 characters) written by `main.py` (Python standard library only) to `/output/entry.txt`, where the make.fun judge reads it.

Run `python3 -S main.py` and it writes the confession to `/output/entry.txt`.
